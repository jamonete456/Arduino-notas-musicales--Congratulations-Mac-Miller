# Arduino-notas-musicales--Congratulations-Mac-Miller
Publico un codigo de Arduino Uno de un fragmento musical de Congratulations, espero q les sirva de algo. 
## Componentes necesarios
* 1x Placa Arduino (Uno, Nano, Mega, etc.)
* 1x Zumbador Pasivo (Buzzer)
* Cables de conexión

## Conexión del circuito
Para escuchar la melodía, conecta el zumbador al Arduino de la siguiente manera:

* **Pin Positivo** Conectado al **Pin Digital 8** del Arduino.
* **Pin Negativo** Conectado a cualquier pin **GND** (Tierra) del Arduino.
